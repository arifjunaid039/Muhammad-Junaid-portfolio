About Me

Aspiring Web Developer & Tech Enthusiast

I'm a web developer based in Pakistan, currently building my skills as a student at Aptech. My journey started with crafting responsive frontend interfaces and has grown into building full, database-driven applications with Laravel and MySQL.

What drives me is turning real-world problems into clean, functional systems — like BackToYou, a full-stack Lost & Found platform, and a Corona Test & Vaccination Management System handling live patient data and admin workflows.

I'm also stepping into leadership: I led Vision Project 2026 as project leader and took it to the exhibition, and I'm now enrolled in TechWiz 7 as a group leader.

Right now I'm expanding into the .NET ecosystem — building with C#, ASP.NET and ASP.NET Core — alongside my PHP & Laravel work, so I can build across both stacks.

When I'm not coding, I'm exploring new tools, sharpening my fundamentals across both stacks, and building side projects to keep leveling up.
